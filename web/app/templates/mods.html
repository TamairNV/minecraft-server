Install it

  1. Get a launcher. Install the Modrinth App or Prism Launcher.
  2. Add the pack. Open the downloaded .mrpack in the launcher. Modrinth App: create an instance and choose From File. Prism: Add Instance, then Import. If your launcher doesn't pick up the pack's icon, download it above and set it in the instance's settings.
  3. Launch and join. {% if address %}Add the server {{ address }} in Multiplayer.{% else %}Ask an admin for the server address, then add it in Multiplayer.{% endif %} You need to be on the whitelist.

The two that matter

Simple Voice Chat

Talk to people near you in game, and hear them fade with distance. It walks you through picking a microphone the first time. Press V for its settings.

Distant Horizons

Draws terrain far past your normal view distance using simplified chunks, so mountains don't pop in. The server sends it what you haven't explored.
